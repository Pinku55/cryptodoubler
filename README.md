# MTASK — Telegram Earning Mini App

MTASK is a production-ready **Telegram Mini App** where users earn **MT** reward
points by watching rewarded ads, completing tasks, claiming daily bonuses and
inviting friends — then withdraw to UPI, Paytm, PayPal, USDT, Binance Pay or
bank transfer.

Built with **PHP 8.3+, MySQL 8+, Bootstrap 5 and vanilla JavaScript** — designed
to deploy on standard **cPanel shared hosting** with **no Composer, SSH, Node.js,
Docker or cron jobs** required.

---

## ✨ Features

### User Mini App
- 🏠 **Home dashboard** — animated balance card (MT + USD), lifetime stats, quick actions, recent activity
- 📺 **Watch Ads** — Monetag rewarded popup with cooldown, daily limits and anti-spam
- ✅ **Tasks** — website visits, shortlinks, Telegram/Instagram/Facebook/Twitter/YouTube/survey, with timer and optional Telegram-membership verification
- 🎁 **Daily Bonus** — 7-day streak ladder (resets on a missed day)
- 👥 **Referrals** — unique code + shareable Telegram link, instant referrer reward
- 💼 **Wallet** — balances, pending, lifetime totals, filterable transaction history
- 💸 **Withdraw** — multiple methods with dynamic custom fields and live status tracking
- 👤 **Profile** — Telegram identity, support, privacy/terms, close app

### Admin Panel
- 📊 Dashboard with KPIs and earnings charts (Chart.js)
- 👥 User management (search, ban, balance adjust, resets, delete)
- 📝 Task management (CRUD, image upload, enable/disable)
- 📺 Rewarded-ads, 🎁 daily-bonus and 🔗 referral configuration
- 💸 Withdrawal processing (approve / reject + auto-refund / mark paid) with CSV export
- 💳 Payment methods with dynamic custom fields
- 🧾 Transactions browser + CSV export
- 📈 Daily / weekly / monthly reports + CSV export
- ⚙️ Settings (branding, economy, Telegram, integrations, SMTP, maintenance)
- 🛡️ Admin audit logs
- 📣 Support: direct messages + batched broadcasts

### Telegram Bot
- Webhook handler with secret-token verification
- Commands: `/start` (+ referral capture), `/help`, `/account`, `/balance`, `/referral`, `/withdraw`
- "Open Mini App" inline button, referral tracking, withdrawal & admin notifications

### Security
Telegram initData HMAC verification · prepared statements everywhere · CSRF
protection · output escaping (XSS) · DB-backed rate limiter · hardened sessions ·
duplicate-reward prevention · IP logging · admin audit trail · protected
directories via `.htaccess`.

## 🚀 Quick Start (cPanel)

1. Upload the project ZIP to your hosting and extract it into your web root.
2. Create a MySQL database + user in cPanel and grant all privileges.
3. Visit `https://yourdomain.com/install.php` and complete the 6-step wizard.
4. **Delete `install.php`** when finished.
5. Open the admin panel at `/admin` and the Mini App at `/app.php`.

See **[docs/DEPLOYMENT.md](docs/DEPLOYMENT.md)** for the full guide.

## 📁 Project Structure

```
/admin            Admin panel (router + pages + layout)
/api              AJAX API endpoints (JSON)
/assets
   /css           Mini App design system
   /js            Mini App SPA controller
   /uploads       User/admin uploaded images (PHP execution disabled)
/bot              Telegram webhook handler
/classes          OOP core (Database, Auth, Telegram, Security, User, …)
/config           Configuration (generated by installer)
/database         schema.sql + default seed data
/includes         bootstrap.php (autoloader, session, boot)
/storage/logs     Application & security logs
app.php           Telegram Mini App
index.php         Public landing page
install.php       Installation wizard
.htaccess         Apache hardening
```

See **[docs/API.md](docs/API.md)** and **[docs/ADMIN_MANUAL.md](docs/ADMIN_MANUAL.md)**.

## ⚙️ Requirements

- PHP 8.3 or newer with `pdo_mysql` and `curl`
- MySQL 8+ (or MariaDB 10.4+)
- Apache with `mod_rewrite`, `mod_headers` (typical on cPanel)
- HTTPS (required by Telegram for Mini Apps and webhooks)
